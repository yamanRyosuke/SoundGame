# 音源解析による譜面生成

音源はブラウザ内で解析する。音の立ち上がり、帯域別の変化、目立つ音の高さから Tap 譜面を作り、Easy / Normal / Hard で間隔と密度を制限する。無音にはノーツを足さない。リズム重視 / バランス / メロディー重視を選べる。

解析は Web Worker で行い、同じ音源・設定から同じ譜面を得る。短時間フーリエ変換の対数スペクトルの正の差分と局所閾値で発音候補を検出する。高さは混合音源の目立つスペクトル成分からの推定であり、ボーカル分離や正確なメロディー採譜ではない。推定テンポは参考表示に使い、検出時刻を強制的に等間隔に丸めない。

生成結果は JSON 保存・読込に対応。音源は含めず、元音源の SHA-256、長さ、レーン、生成設定、ノーツを保存する。同じ音源を選んで読み戻す。入力判定の補正（正値は遅い入力を許容する）も保存する。

安全な負荷上限として音源は100 MB・15分まで。解析のキャンセル、進捗表示、失敗時の再試行を提供する。曲や生成設定の切替中とプレイ中は編集をロックする。

## 検証

合成音源で発音時刻、無音、音色・高さの変化、難易度の間隔制限、再現性を検証する。音源読込失敗と再生終了・再挑戦、JSON の検証も対象とする。実曲の聴感と楽しさはユーザーによるプレイ調整が必要。

### 2026-10-16 の確認結果

- `npm test`: 8件成功。合成音源の発音検出は45 ms以内、定音量での音高変化検出、逆相ステレオ、無音、難易度別の間隔・密度、同一設定の再現性、JSON検証、再生ライフサイクル、キーリピート抑制を確認。
- `npm run build`: 成功。Three.jsを含むメインバンドルに500 kB超のサイズ警告あり。
- Codex内蔵ブラウザ: 付属の24秒音源でNormal/バランス35ノーツ、Hard/メロディー重視60ノーツ。8秒の独自WAVで12ノーツ、入力による得点、自然終了、再挑戦を確認。
- ブラウザでJSONダウンロードと同じ音源への読込に成功。別の音源では読込を拒否。壊れた音源の読込に失敗しても元の曲と譜面は保持。
- 音源の実際の聴感、端末の出力遅延、曲ごとの譜面の楽しさは未評価。合成信号の検出精度と、人がプレイして感じるタイミングは別途調整が必要。

## 4レーン表示（2026-10-16）

- A / W / S / Dを0.36単位間隔で配置。初期の円では内側からこの順。
- 時刻から距離への変換は中心線の弧長テーブルだけを使う。各レーン独自の距離時計は作らない。同じ時刻の横断位置から線・ノーツ・判定バー・エフェクトを配置する。
- カーブでは外側の移動距離が長くなるが、4本の進行率と判定タイミングは同じ。内側が先行することはない。
- オフセット線は頂点の法線を使ったマイター接続。鋭角の突き出しは2倍までに制限。レーン幅より小さな半径の急折り返しでは線同士が交差しうるため、ステージ形状には十分な曲率半径を確保する。
- 既存の譜面JSONはそのまま利用できる。画面下の補助ガイドも同じキー順・色の4段表示。
- `npm test`: 13件成功。直線の等間隔、円の共通角度と閉路端、左右に曲がる非対称経路、ノーツ・バー・エフェクトの一致、重複頂点を検証。`npm run build` 成功。ブラウザで4本の表示・バーの移動・キー別ノーツ・自然終了を確認。

## レーン数の切り替え（2026-10-16）

- 開発パネルで1〜4本を選択。1本 `[A W S D]`、2本 `[A W] [S D]`、3本 `[A W] [S] [D]`、4本 `[A] [W] [S] [D]` の固定割り当て。
- `createLaneLayout` が線の位置・担当キーを一元管理。共有レーンは中立色、ノーツと文字は元のキー色。レーン・バー・エフェクト・ガイド・凡例をまとめて更新する。
- 切り替えは停止中のみ。譜面を再解析せず、既存のノーツ時刻とキーを保って再配置し、スコアをリセットする。
- JSONの省略可能フィールド `laneCount` に保存する。旧形式の省略時は4本、1〜4の整数以外は読込を拒否する。
- テスト18件成功。全レーン数で4キーの重複・欠落がないこと、カーブ上でノーツ・バー・エフェクトが一致すること、JSON往復・旧形式・不正値を確認。ブラウザで1→2→3→4→2の切り替え、ノーツ数の維持と2本での再生を確認。
