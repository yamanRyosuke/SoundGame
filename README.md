# One Stroke Rhythm Game / SoundGame

## 概要
音楽に合わせて一筆書きのレーンを進み、W / A / S / D を押す Web 音楽ゲームです。

開発パネルの「レーン数」で1〜4本に切り替えられます。ノーツと判定エフェクトは対応するキーの線に表示され、カーブでも全レーンで同じ進行位置を保ちます。

画面はほぼ白の紙を基調に、色鉛筆・クレヨン風のレーンを描画します。輪郭の細かな揺らぎ、筆圧の濃淡、顔料のかすれはコース上に固定され、進行位置や判定には影響しません。共有レーンは鉛筆色、4キーは落ち着いた赤・青・緑・黄土色です。

| レーン数 | レーン順のキー割り当て |
| --- | --- |
| 1本 | A・W・S・D |
| 2本 | A・W ／ S・D |
| 3本 | A・W ／ S ／ D |
| 4本 | A ／ W ／ S ／ D |

停止中に切り替えると、現在の譜面の時刻・キーを保って線への配置だけが変わります。共有レーンでも、ノーツに書かれたキーを押してください。レーン数は譜面JSONにも保存され、古いJSONは4本として読み込まれます。

## プレビューコース

開発パネルの「ステージの形」で、次の周回コースを選べます。最初はワインディングを表示します。比較用に小さな円も残しています。

| 形 | 特徴 | 1周（進む速さ3.5のとき） |
| --- | --- | --- |
| ワインディング | 直線と大小のカーブをつないだ周回 | 約23秒 |
| クローバー | 4つのふくらみとくびれを巡る周回 | 約22秒 |
| 立体8の字 | 中央に高低差のある立体交差 | 約26秒 |

判定バーは一定の速さで進み、**曲が終わるまでコースを周回し続けます**。曲の長さによって速さは変わらないので、長い曲でもノーツが詰まりません。速さは `進む速さ`（2〜6、初期値3.5）で変えられます。ノーツの時刻は変わらず、並ぶ間隔だけが変わります。短いコースで次の周のノーツが重ならないよう、先読みは1周より短く表示します。

形の変更は停止中に行えます。ノーツの時刻・キーと音源は保たれ、スコアはリセットされます。全コースで1〜4レーンを使えます。

つづら折りとスパイラルは片道で周回できないため、選択肢から外しました。これらの形で保存したステージや譜面JSONは、ワインディングで開きます（ノーツはそのまま）。

譜面JSONには形とレーン数も保存され、読込時に復元します。従来の円コースのJSONも読み込めます。

## 音源からステージを作る

1. `音源を選ぶ` で手元の音声ファイルを選びます（100 MB・15分以内）。ブラウザ内で解析し、外部に送信しません。
2. Easy / Normal / Hard と、バランス / リズム重視 / メロディー重視 / 音色で統一を選び、`譜面を生成` を押します。
3. `START` で試遊します。画面下の目印が白い判定線に重なったら、その文字のキーを押します。Esc または停止ボタンで中断できます。
4. `保存したステージ` で名前を付け、`音楽ごと保存` を押します。後日は保存済みステージから選び、`選んだステージを開く` → `START` で再び遊べます。

音の立ち上がり・音色・目立つ音の高さの変化から譜面を作ります。「音色で統一」では、曲中の似た音（例: バスドラム、スネア、ハイハット）を2〜4種類にまとめ、同じ種類の音には同じキーを割り当てます。低い音ほど左のキー（A）、明るい音ほど右のキー（D）になります。楽器の分離や正確なメロディー採譜ではありません。難易度はノーツの密度と押しやすさを変え、判定の厳しさは別に設定できます。入力の早い／遅い表示を見て、設定のタイミング補正も調整できます。

設計と制約は [音源解析による譜面生成](docs/musical-chart.md) を参照してください。

## 音楽付きステージの保存

- 音源の元ファイル、生成済みノーツ、コースの形、レーン数、入力タイミング補正、判定・生成設定をブラウザ内の一覧に保存します。付属の音楽も、読み込んだ音楽も保存できます。読込時は音楽を選び直したり、譜面を再生成したりする必要がありません。
- 保存は毎回別のステージとして追加するので、同じ曲の難易度・形違いも残せます。ページを閉じても同じブラウザ・同じ配信元（ホストとポート）で呼び出せます。音源は外部へ送信しません。
- `音楽入りファイルを書出し` は、現在の音楽とステージを1つの `.soundstage` ファイルにまとめます。別のブラウザやPCでは `音楽入りファイルを読込` で開けます。読み込んだファイルは保存一覧にも追加します。
- ブラウザのサイトデータを消すと保存一覧も消えます。大切なステージは `.soundstage` ファイルでも保管してください。容量不足などでブラウザに保存できない場合も、ファイル書出しは使えます。
- 以前の譜面JSONは `譜面JSON（音源別）` から利用できます。こちらは元の音源を別途選ぶ必要があります。

## カメラと画面下のガイド

- プレイ中のカメラは、標準で現在地の判定バーを拡大して追います（開発パネルの `カメラ` → `プレイ中のカメラ`）。
  - 現在地を追う（進行方向が上）: カーブでもコースの先が画面の上に来るよう回ります。A のレーンは常に左、D は右です。
  - 現在地を追う（向きは固定）: 拡大して追いますが、画面の向きは変えません。
  - コース全体を表示: 従来の全体表示です。
- `カメラの距離`（0.5〜2.5倍、初期値1.5倍）で、追従中のカメラの近さを変えられます。左に動かすと近く大きく、右に動かすと遠く広く映ります。プレイ中も動かせます。
- 停止中と曲の終了後は、コース全体を表示します。全体表示の大きさは `判定・表示の調整` → `全体表示の拡大` で変えられます。
- **Shift + P** で、開発パネルと画面下の譜面ガイドをまとめて隠したり出したりできます。隠すとコースが画面いっぱいに広がり、左上に戻し方を表示します。文字入力欄にフォーカスがあるときは反応しません。
- `画面下の譜面ガイドを表示` を外すと、下のガイドを消して上のコースだけで遊べます。空いた分だけコースの表示が広がります。カメラ・距離・ガイド・パネル表示の設定はブラウザに記憶します。

## 判定エフェクト

- Perfect: 黄土色の二重の輪、光線、舞い上がる粒
- Great: 緑の太い輪と短い光線
- Good: 青い小さな輪がすぐ消える
- Miss: 赤い×が揺れながら沈む

左上の判定文字も、Perfect ほど大きく弾み、Miss では横に揺れます。

## キャラクター

Perfect・Great・Good を取ると、手描きのキャラクターがコースの脇に飛び出します。判定ごとに出てくる顔ぶれが違い、Miss では何も出ません。

| 判定 | キャラクター | 大きさ |
| --- | --- | --- |
| Perfect | にっこり顔・豆・星（`character_d` / `e_1` / `i`） | 大 |
| Great | `character_j` / `h` / `g` | 中 |
| Good | `character_a` / `b` / `c` | 小 |

キャラクターは、紙から切り抜いたように3D空間に立ち、いつもカメラのほうを向きます。少し先の位置に飛び出してそこに残り、ぷにぷに跳ねる・ころころ転がる・ぷるぷる揺れる・跳んでくるっと回る、のどれかをずっと続けます。周回すると、前の周で出てきたキャラクターにまた会えます。80体を超えると、古い順に縮んで消えます。次に START を押すと、全員いなくなります。

## プレイ方法
- 操作方法: W / A / S / D、Esc で停止
- ゲームパッド（Xbox コントローラー）: X = A、Y = W、A = S、B = D。ボタンの並びは W/A/S/D と同じひし形です。メニューボタンで START / 停止。コントローラーを押すと画面のキー表示が X / Y / A / B に切り替わり、キーボードを押すと元に戻ります。
- 対応ブラウザ: Web Audio / Web Worker / WebGL 対応のPCブラウザ。HTTPS または localhost で起動してください。

### itch.io 版

`vite.config.js` は相対パス（`base: './'`）でビルドします。`dist/` の中身を、`index.html` が直下に来るように `SoundGame_itch.zip` にまとめ、itch.io の「This file will be played in the browser」としてアップロードします。キー入力はゲーム画面を一度クリックしてから有効になります。

```bash
node tests/make-browser-fixture.js
```
